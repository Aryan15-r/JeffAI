🚨 seek() and tell() — Often Missed! (CBSE 2024)

2 Types of Transmission Media

Guided (Wired): Uses cables/conductors. Connection-oriented.
Unguided (Wireless): Waves through air, water, vacuum. Connectionless.

1. Twisted Pair Cable

2 identical copper wires wrapped in double helix. Twisting reduces crosstalk.

Crosstalk: Bleeding of signal from one wire to another → corrupts signal.

Range: 100 metres

Speed: 1Mbps (no conditioning), 10Mbps (with conditioning)

Types:

  • UTP (Unshielded Twisted Pair): CAT-1 to CAT-8 (more efficient)
  • STP (Shielded Twisted Pair): Extra shielding against external interference

Advantages: Simple, easy to install, low weight, inexpensive

Disadvantages: Low BW, unsuitable for broadband, max 1/10Mbps

2. Coaxial Cable

Solid wire core surrounded by foil/wire shield, separated by plastic insulator. Inner core carries signal; shield provides ground.

High electrical properties → suitable for high-speed. Used in TV signals and security systems.

Types:

  • Thicknet: Range = 500m
  • Thinnet: Range = 185m

Speed: 100–400 Mbps

Advantages: Higher bandwidth (100–400Mbps), good for shared cable networks

Disadvantages: Expensive, NOT compatible with twisted pair

3. Optical Fibre Cable

Thin glass strands carrying light beam. Structure: Core + Cladding + Protective Coating

Light sources: LED (Light Emitting Diode) / LASER diode

Types:

  • Single mode: Range = 5 km
  • Multimode: Range = 9 km

Speed: 100 Gbps ← FASTEST!

Advantages: Secure, very high capacity, used in broadband, suitable for harsh areas

Disadvantages: Complex installation, expensive, difficult to solder

Q1. Why does -11%4 give 1 and not -3 in Python? 2M
In Python, the modulo result has the same sign as the DIVISOR (not dividend). Formula: a%b = a - b*(a//b). -11//4 = -3 (floor division rounds toward -∞). -11 - 4×(-3) = -11+12 = 1. This differs from C/Java where result has sign of dividend.
Q2. Why is 2**2**3 = 256 and not 64? 2M
The ** (exponentiation) operator is RIGHT-associative in Python. So 2**2**3 = 2**(2**3) = 2**8 = 256. NOT (2**2)**3 = 4**3 = 64. This is the opposite of + and - which are left-associative.
Q3. What is the difference between a list and a tuple in terms of use cases? When would you prefer tuple over list? 2M
List = mutable (can change). Tuple = immutable (cannot change).
Use tuple when: data should not change (like student roll numbers, coordinates), as dict keys (lists cannot be), for faster iteration (tuples are slightly faster than lists), to protect data from accidental modification.
Q4. Can a function return more than one value in Python? How? 2M
YES. Python function can return multiple values as a tuple implicitly. def f(): return a, b, c — the returned values are packed into a tuple. At call site: x,y,z = f() unpacks them. This is unique to Python.
Q5. What happens if you open a file that doesn't exist in 'r' mode? In 'w' mode? 2M
'r' mode → FileNotFoundError (exception is raised, program crashes).
'w' mode → File is CREATED automatically. No error raised. If file exists, it is ERASED.
Q6. Why does a stack cause NameError when pop is called on empty stack in Python? How to prevent? 2M
Calling pop() on empty list raises IndexError (not NameError). Prevent by always checking: if len(stack)==0: print("Underflow") before popping. This is called the UNDERFLOW condition.
🧠 HOTS — Networks & SQL
Q7. A company uses hub in all departments but faces slow network. What device should replace hub and why? 2M
Switch should replace Hub. Hub BROADCASTS data to all nodes creating collisions and wasting bandwidth. Switch UNICASTS — sends data only to the specific destination node, creating temporary dedicated connections. This eliminates unnecessary traffic and significantly improves speed.
Q8. Why does optical fibre have higher data transmission capacity than copper cables? 2M
Optical fibre uses LIGHT for transmission, which travels at ~300,000 km/s — much faster than electrical signals in copper. Light signals don't suffer from electromagnetic interference, have much higher frequency range, and very low signal loss (attenuation). This gives fibre ~100Gbps vs copper's 10Mbps-1Gbps.
Q9. Why can't we use WHERE instead of HAVING with aggregate functions? 2M
WHERE clause is evaluated BEFORE GROUP BY — it operates on individual rows before they are grouped. Aggregate functions (COUNT, SUM, AVG) are calculated AFTER grouping. So when you write WHERE AVG(Marks)>75, the AVG hasn't been calculated yet when WHERE runs. HAVING operates after GROUP BY when aggregate values are available.
Q10. Difference between DELETE FROM Student and TRUNCATE TABLE Student. When to use each? 2M
DELETE: Slower, removes rows one by one, fully logged, can be rolled back, can use WHERE clause, triggers fire.
TRUNCATE: Faster, removes all rows at once, minimal logging, usually cannot roll back, no WHERE clause, triggers don't fire.
Use DELETE when you need to delete specific rows or might need to rollback. Use TRUNCATE when you need to quickly empty entire table.
Q11. Why do we need commit() after INSERT/UPDATE/DELETE but not after SELECT? 2M
INSERT/UPDATE/DELETE are DML operations that MODIFY data. MySQL uses transactions — changes are first written to a transaction log (temporary). Without commit(), changes exist only in the temporary buffer and are lost when connection closes. SELECT only READS data — nothing is modified, so no commit needed. Commit permanently writes the transaction to the database.

C1. What is an undefined variable in Python? Give an example. 2M
In Python, a variable is created only when a value is assigned to it. If we try to USE a variable before assigning, it causes a NameError (undefined variable). 
print(x)  # NameError: name 'x' is not defined
x = 20

C2. What is the error in: X, Y = 7? 1M
TypeError — Two variables on left but only one value on right. Cannot unpack a single integer into two variables.
Fix: X, Y = 7, 8
C3. Can nongraphic (non-printable) characters be used in Python? How? 2M
Yes — using escape sequences.
\n = newline, \t = tab, \b = backspace, \r = carriage return, \\ = backslash, \' = single quote.
C4. Which of these is NOT a legal numeric type in Python? (a) int (b) float (c) decimal 1M
decimal is NOT a built-in numeric type. Python has int, float, and complex as built-in numeric types. decimal is a module, not a type.
C5. What is the difference between domain and degree in a relational database? 2M
Domain: The set of all possible values an attribute can hold. E.g., domain of "Grade" = {A, B, C, D, F}; domain of "Age" = positive integers 0–150.
Degree: The number of attributes (columns) in a relation/table. E.g., a table with Name, Age, Marks has degree 3.
C6. What is meant by "giving an alias" in SQL? Give example. 1M
An alias is a temporary name assigned to a table or column in SQL for the purpose of a particular query, using the AS keyword.
E.g., SELECT Price * Qty AS AMOUNT FROM ITEMS; — AMOUNT is the alias for the calculated column.
C7. Why is a switch called an "intelligent hub"? What is the key technical difference? 2M
A hub is a dumb device that broadcasts every packet to ALL connected ports regardless of the destination — causing collisions and wasted bandwidth.
A switch is "intelligent" because it maintains a MAC address table. It learns which device is on which port and sends data ONLY to the specific destination port. This eliminates unnecessary traffic and collisions.
C8. A student writes: def f(x=10, y): print(x+y). What error occurs and why? 2M
SyntaxError: non-default argument follows default argument
In Python, all parameters with default values MUST come AFTER parameters without default values. Since y has no default but comes after x=10 (which has a default), Python cannot determine how to assign positional arguments.
Fix: def f(y, x=10): print(x+y)
